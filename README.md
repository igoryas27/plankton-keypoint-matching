# Поиск общих ключевых точек на микрофотографиях планктона

Учебный проект по компьютерному зрению: SIFT + проверка соответствий на шести изображениях *Bosmina longirostris*.

**GitHub:** https://github.com/igoryas27/plankton-keypoint-matching

## Содержание

- `plankton_sift.ipynb` — основной **выполненный** Jupyter Notebook: код, таблицы, графики и пояснения.
- `images/` — шесть исходных фотографий.
- `results/` — визуализации и `stats.json`.
- `plankton_report.pdf` — отчёт с результатами и ссылкой на репозиторий.
- `make_report.py` — скрипт пересборки PDF после запуска ноутбука.
- `analysis.py` — тот же вычислительный эксперимент в виде Python-скрипта.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook plankton_sift.ipynb
```

В Jupyter выберите **Run All**. Запускать из корневой папки проекта, где есть папка `images/`. Для повторного создания PDF выполните `python make_report.py` после ноутбука.

Также можно выполнить `python analysis.py`, чтобы пересчитать статистику и визуализации без Jupyter.

## Метод

1. Сохранение пропорций и уменьшение максимальной стороны до 1400 px.
2. SIFT с `nfeatures=3000`, `contrastThreshold=0.025`, `edgeThreshold=12`, `sigma=1.6`.
3. BFMatcher с L2, Lowe ratio test (`0.75`), обратная проверка соответствий.
4. RANSAC по частичному аффинному преобразованию с порогом репроекции 5 px.
5. Поиск глобальных треков, согласованных во всех 15 парах изображений.
6. До 30 общих точек с одинаковыми номерами — если таковые существуют.

**Итог:** на этих снимках разных особей строгий алгоритм не подтвердил общих точек на всех шести фотографиях. В ноутбуке показаны промежуточные совпадения и причины их отбрасывания.
